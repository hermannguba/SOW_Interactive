# SOW_Interactive

Ядро сцены для схем проката: проект, зал, дата мероприятия и плот.

Зал хранит постоянную геометрию и звуковые порталы. Плот на дату хранит слои и приборы. Свет, звук и видео лежат в одном графе. Слой только фильтрует чтение внутри дисциплины. Оси: X — ширина зала, Y — глубина, Z — высота. Поворот в градусах.

Интерфейса, импорта и отрисовки здесь нет.

```bash
npm test
npm run typecheck
```

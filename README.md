# SOW_Interactive

Ядро сцены для схем проката: проект, зал, дата мероприятия и плот.

Зал хранит постоянную геометрию и звуковые порталы. Плот на дату хранит слои и приборы. Свет, звук и видео лежат в одном графе. Слой только фильтрует чтение внутри дисциплины. Оси: X — ширина зала, Y — глубина, Z — высота. Поворот в градусах.

Вид сверху (X/Y), вид сбоку (X/Z) и вид 3D читают один граф и один фильтр. Страница `web/` показывает их на демо-зале: библиотека ставит прибор на видах сверху и сбоку, карточка меняет тип, слой и адрес света. Импорт DWG кладёт линии файла подложкой зала и не создаёт приборы. Импорт MVR добавляет световые приборы в плот выбранной даты: тип, позицию, поворот, юниверс и адрес. В 3D видны геометрия зала, порталы, приборы выбранных дисциплины и слоя и подложка DWG, если она есть у зала. Лучей и управления приборами в 3D нет.

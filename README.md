# SOW_Interactive

Ядро сцены для схем проката: проект, зал, дата мероприятия и плот.

Зал хранит постоянную геометрию и звуковые порталы. Плот на дату хранит слои и приборы. Свет, звук и видео лежат в одном графе. Слой только фильтрует чтение внутри дисциплины. Оси: X — ширина зала, Y — глубина, Z — высота. Поворот в градусах.

Вид сверху (X/Y) и вид сбоку (X/Z) — чистые проекции графа. Страница `web/` показывает их на демо-зале: библиотека ставит прибор, карточка меняет тип, слой и адрес света. Импорт DWG кладёт линии файла подложкой зала и не создаёт приборы. Импорт MVR добавляет световые приборы в плот выбранной даты: тип, позицию, поворот, юниверс и адрес. 3D и лучей нет.
